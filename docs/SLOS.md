# SLOs and Error Budgets

Versioned initial SLO records may govern API availability, authenticated success, workflow start, job completion, notification processing, sync freshness, provider verification, report delivery, backup success, RPO, and RTO. Each definition records its SLI, target, window, exclusions, source, quality requirements, owner, alert policy, version, and effective period. Empty input returns missing. Error budgets never relax security, isolation, approval, or verification gates.
