# Anomaly, Insight, and Attribution Methodology

Deterministic anomalies declare baseline, minimum samples, threshold, freshness, and method. Missing data creates a quality issue, not a performance anomaly. Insights cite validated metric versions and limitations. AI summarizes frozen validated snapshots but never calculates metrics or omits unfavorable results. Attribution declares model/version, evidence, lookback, weights, coverage, uncertainty, and never claims objective causation.
