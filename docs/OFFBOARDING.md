# Offboarding

Plans are organization-owned, versioned and audited with planned, in-progress, blocked, completed,
and cancelled states. They contain product, entitlement, integration, workflow, notification,
export, retention, access, and final-audit steps. Completion requires evidence for every blocker.

Phase 4 records the plan; it does not cancel workflows, disconnect providers, delete data, remove
access, archive the organization, or send notifications. High-risk changes require AAL2.
