# Operator Diagnostics

Authorized AAL2 diagnostics expose release, migration head, environment, readiness, heartbeats, queue depth, stale leases, provider/connection health, synchronization freshness, notification backlog, AI health, audit protection, backup freshness, incidents, and maintenance controls. They never expose credentials, tokens, payloads, personal data, database URLs, or unrestricted records. Production route mounting remains dependent on the approved operator identity model and is not public.
