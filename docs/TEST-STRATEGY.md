# Master Test Strategy

Release-blocking suites map identity, tenant isolation, authorization, onboarding, providers, products, durable execution, maintenance, incidents, migrations, restore, and frontend workflows to unit, integration, contract, failure, browser, and accessibility tests. Security-critical authorization/isolation branches require explicit negative tests; connector and external-action paths require idempotency, verification, and reconciliation evidence. Local throughput results are capacity signals only, never production guarantees.
