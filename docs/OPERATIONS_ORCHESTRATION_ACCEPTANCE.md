# Operations orchestration acceptance

For a connected single-location client with Google and GitHub configured:

1. Integrations reports the mapped business by name and uses the GBP location's actual last-sync timestamp.
2. Automations can run GBP sync, reviews ingestion, and GBP AI post generation immediately for a selected platform location; recurring schedules can be created, paused, resumed, and have their cadence changed.
3. Active schedules with a past next-run timestamp are visibly marked overdue rather than presented as healthy.
4. A single GitHub App repository becomes an active `primary-site` publishing target without requiring a second credential or PAT workflow.
5. SEO analysis converts crawl issues, valid Search Console query observations, and PageSpeed findings into durable SEO opportunities and mirrors them into Content opportunities.
6. GBP AI generation requires approved business facts, uses provider/website knowledge plus recent-post history, creates an approval-required post revision, attaches a relevant page CTA when available, and selects only Drive images whose folder path matches the client identity.
7. Provider publication remains approval-gated and verifies the resulting Google resource.
