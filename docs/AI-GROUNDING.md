# Shared AI Grounding

Reviews and Content use one registered-task gateway. Every request is tenant-scoped, task/versioned, budget/latency bounded, sensitivity classified, and grounded by approved business-fact revision references. Secrets and unrelated tenant data are rejected. Provider/model/provenance, input references, output hash/revision, usage, failure, validation, and human-review requirement remain attributable. Failed and rejected generations are retained according to policy. CI uses deterministic providers without network.
