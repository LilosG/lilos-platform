# Content Product

Content begins with evidence-bearing opportunities and structured briefs. Manual or shared-AI drafts create immutable revisions that reference approved fact revisions. Validation rejects missing grounding, prohibited claims, unsupported targets, secret-like content, executable markup, and unsafe repository paths. AI output is never approved automatically.

Editorial and client approval are distinct, revision-specific stages. Material changes create a new revision. Publishing stores intent before repository work and separately tracks branch creation, pull request, checks, merge, deployment, and verification. Pull-request creation is not publication; build success is not deployment. Ambiguity reconciles. Rollback creates a new controlled publication and never erases history.
