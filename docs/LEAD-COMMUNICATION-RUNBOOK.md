# Lead Communication and Suppression Runbook

Before every attempt verify tenant, destination, consent type, current consent evidence, active suppression, quiet hours, workflow state, runtime controls, provider capability, and idempotency. Persist intent before Phase 6 delivery. Sent is not delivered; acknowledgment is not human contact. Reply, opt-out, conversion, suppression, terminal status, or policy stop cancels remaining jobs. Ambiguous delivery reconciles and is not blindly resent.
