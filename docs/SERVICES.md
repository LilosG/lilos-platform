# Governed service catalog

Services are organization-owned offerings with immutable scoped keys, active/archived lifecycle,
optimistic updates, deterministic listing, and immutable audit evidence. Assignments explicitly
select organization or same-organization location scope; no service is inferred for every location.
Removed assignments remain historical and grant no entitlement, permission, readiness, integration,
or workflow behavior.

The catalog is distinct from profile `primary_services`: profile lists remain controlled narrative
context. Provider mappings are deferred to the integration foundation.
