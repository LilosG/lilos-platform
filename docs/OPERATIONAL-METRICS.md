# Operational Metrics Catalog

Initial families are `api.*`, `database.*`, `workflow.*`, `jobs.*`, `notifications.*`, `providers.*`, `synchronization.*`, `ai.*`, `gbp.*`, `reviews.*`, `leads.*`, `content.*`, `seo.*`, `insights.*`, `backup.*`, and `deployment.*`. Allowed labels are service, environment, product, provider, operation, outcome, and HTTP status class. Tenant names, IDs, URLs, emails, resource IDs, and error messages are prohibited labels. Missing measurements remain missing.
