# Product readiness

Readiness is computed read-only over entitlement, organization/location lifecycle, selected
locations, required profiles, approved facts, valid configuration, approval policy, runtime
controls, onboarding blockers, and declared integrations. It performs no external call and stores
no snapshot.

Results contain selected locations, referenced versions, UTC evaluation time, and deterministic
blocking/warning findings. Missing integration records remain blocking until the later integration
foundation. Enablement never implies readiness, and readiness never implies authorization.
