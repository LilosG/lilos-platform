# Product entitlements

One organization-owned entitlement may exist per registered product. Selected locations are
explicit same-organization records. The versioned lifecycle supports not enabled, setup,
configuration or connection required, ready, active, paused, degraded, suspended, and archived.
There is no physical deletion.

Entitlement is eligibility only. It grants no membership, permission, readiness, feature flag,
runtime permission, integration, or billing-provider state. Activation requires a fresh successful
shared readiness evaluation.
